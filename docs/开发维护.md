# 开发与维护

## 运行环境

使用 Bun（https://bun.sh）。本项目已生成的 `index.html` 不依赖构建工具，使用网页不需要安装 Bun；修改源码和运行本地服务才需要。

```sh
bun install --frozen-lockfile
bun run build
bun test
bun x tsc --noEmit
bun run start
```

## 文件结构

| 文件 | 用途 |
| --- | --- |
| `index.html` | 可直接打开的单文件学习网页 |
| `app/content.ts` | 8 个章节、57 个知识点、选择题干扰项和主观题要点 |
| `app/main.ts` | 闪卡、测验、错题、进度保存和导入导出 |
| `app/style.css` | 页面布局和移动端适配样式 |
| `app/build.ts` | 将脚本、样式、题库、逐字稿打包进 HTML |
| `app/server.ts` | 本机服务，默认监听 `127.0.0.1:4318` |
| `app/app.test.ts` | 内容和交互自动化测试 |
| `docs/screenshots/` | 实际浏览器页面截图 |
| `README.notes.md` | 原仓库项目说明 |
| `全文.md`、`精华.md`、`guides/` | 保留的原始学习资料 |

## 修改题库

`app/content.ts` 每条知识点包含章节、视频时间、标题、题目、正确答案、三个错误选项、主观题及三个评价要点。

新增或修改知识点时：

- 时间点应来自逐字稿，并核对上下文；精确引用建议回看视频。
- 正确答案与三个干扰项不能重复；题目应只有一个最符合访谈的答案。
- 章节必须对应已定义的章节编号。
- 区分嘉宾观点和独立事实，不用未经验证的说法考查“事实正确性”。

当前主观题练习使用题库中隔一个取一个的知识点，共 29 题。综合测验按章节随机抽取；如调整章节，保证每章至少有一条主观题候选，以及两条不同的选择题候选。

修改源码或逐字稿后必须重新运行 `bun run build`，并提交更新后的 `index.html`。本地服务提供的是生成后的 HTML，而不是实时编译源码。

## 验证范围

10 个自动化测试覆盖题库完整性、57 道选择题判分、闪卡记录、错题处理、主观题自评、24 题跨章节抽题、未答题判分、记录恢复和逐字稿导航。

另通过 TypeScript 检查。2026-10-12 使用实际浏览器查看并保存学习地图、闪卡、选择题和主观题截图；截图为桌面视口，移动端布局尚未单独验收。

## 存储与隐私

数据保存在当前浏览器的 `localStorage`，键为 `podcast-study-v1`。没有后端账号、云同步或 AI 批改请求。视频和来源链接由读者主动打开。

截图使用独立访问来源的初始状态，不包含个人学习回答或已有学习进度。请勿把导出的个人学习记录提交到公开仓库。
